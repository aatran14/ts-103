1.1 The Beginning

In ts-101, Slim notes on the origins of Typescript, in particular, that it was designed to migrate large scale JavaScript systems and retyped into Typescript.

Why? Large companies, namely Microsoft, were operating on millions of lines of JavaScript, but nobody could "fix" or "build" anything. On a local scale, folks could write small JavaScript programs, but it was easy to make one change and somehow break something many files away. Every new line of code was basically a bug.

Enter Anders Hejlsberg (who build C# and Turbo Pascal).

Anders worked on a neat idea. What if you could add types to JavaScript in a way that is optional? You do not rewrite. You annotate the existing infrastructure. In essence, Javascript is valid TypeScript, so get everyone to just annotate the JavaScript to be typed. As t approaches infinity, the whole system goes from .js to .ts!

What does this look like?

// plain JavaScript - no types, no safety
function greet(name) {
  return "Hello, " + name;
}

greet(42); // no error. JavaScript doesn't care.
// the same function, annotated with TypeScript
function greet(name: string): string {
  return "Hello, " + name;
}

greet(42); // error: type 'number' not assignable to 'string'

Simply, it was a migration tool for massive codebases, designed for folks who were used to writing in JavaScript, and steer them into a world where there is safety. Alice can now make a change to the knowledge base and know if it broke Bob's tool.

Ah, but there's a catch. It's unreasonable to migrate the entire codebase from JavaScript into TypeScript. Folks can opt-in to using any.

1.2 The Deadly Sins

any

any is the original sin. It allows a person to ignore type. It can be assigned to anything. Quite literally, it's the absence of typing.

any in the form of a Pragma?

@ts-ignore

any in the form of a Flag?

--suppressImplicitAnyIndexErrors

Of course, there are more evils out there:

  Casts: x as Foo
  
  Tell the TypeScript to treat value x as type foo

Here, a lesser evil: Ever been scared of lying?

Write a function that checks at runtime whether x is a type Foo.

  Type guards: f(x: unknown): x is Foo
  
  If the arbitrary function returns true, you can treat x as type Foo
