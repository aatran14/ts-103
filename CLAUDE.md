## About TypeScript 101

TypeScript 101 by Slim Lim covers foundational TypeScript concepts for developers already using the language professionally. Key topics include:

- **Types vs. Values**: Compile-time type annotations vs runtime JavaScript values; "types approximate values"
- **Structural Subtyping**: Shape-based compatibility where an object with more properties is the subtype (counterintuitive: "a valid subtype must contain a superset of fields")
- **Escape Hatches**: Critiques misuse of `any`, `@ts-ignore`, and type casts; advocates `unknown` as safer alternative
- **Type Refinement**: Discriminated unions and exhaustiveness checking to "make invalid states unrepresentable"

The presentation emphasizes practical TypeScript usage focused on correctness rather than gradual migration strategies.
